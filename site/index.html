Os mods

Os mods de hoje. Mexa neles aqui mesmo.

Um mod muda um pedaço da interface do Claude Code: uma faixa acima do prompt, um painel, um botão. Cada um liga e desliga sozinho, no terminal e no app desktop. São dois por enquanto, e a lista cresce.

01barra-de-usoapp e terminal

Quanto da sessão já foi, num relance.

Uma faixa acima do prompt com o contexto da sessão, a janela de 5h e a semana. No app, o contexto é uma praia: o mar avança sobre a areia e, quando passa do meio-fio do calçadão, vira ressaca.

  • Contexto: a praia. O calçadão começa em 85%. Mar na pedra é hora de pensar num /compact.
  • 5h: o pôr do sol. O sol desce conforme a janela é usada e mostra o horário em que ela renova.
  • 🐚 Explain. No app, explica um pedido de permissão numa conversa lateral, com uma faixa de risco, sem executar nada.
  • Ajustes (⚓). Você escolhe o que aparece. Eles valem nas sessões seguintes.

02farolapp e terminal

Qual sessão espera você, sem abrir uma a uma.

O estado de todas as sessões do Claude Code abertas na máquina, na faixa e num painel. Quando uma delas pede uma permissão ou faz uma pergunta, o farol acende.

  • Na faixa. A torre do farol acende em vermelho quando alguma sessão espera você.
  • No painel. Um cartão por sessão, na ordem da atenção; no macOS, um clique leva o app para ela.
  • Som. Um aviso quando a sessão passa a esperar você. Dá para desligar ou baixar o volume.
  • No terminal também. O mesmo painel em cartões de texto, sem animação.
claude plugin install farol --marketplace https://github.com/orladigital/mare-mods.git

    Instalar

    Um comando. Sem conta, sem chave.

    O repositório é público: não precisa de conta no GitHub nem de chave SSH. Os mods são os mesmos no app desktop e no terminal; o que muda é só por onde você instala.

    Quais mods
    Instalar pelo
    Ainda não viu os mods? Veja o que cada um faz

    1. Clique no + ao lado do prompt, depois em Plugins e em Add marketplace, e informe:

      https://github.com/orladigital/mare-mods.git

    2. Clique em Add plugin e escolha barra-de-uso; depois, de novo, farol.

    3. Feche e abra o app (Cmd+Q), para as sessões já abertas pegarem os mods.

    1. Rode no terminal, fora de uma sessão do Claude Code, um comando por mod:

      claude plugin install barra-de-uso --marketplace https://github.com/orladigital/mare-mods.git
      claude plugin install farol --marketplace https://github.com/orladigital/mare-mods.git

      Dentro de uma sessão, o mesmo comando começa com /plugin install.

    2. Aceite o marketplace (y) e escolha o escopo de usuário, para o mod valer em todos os projetos.

    3. Abra uma sessão nova. O mod passa a valer nas sessões novas, no terminal e no app.

    Requisitos: Claude Code 2.1.316 ou mais novo e o git instalado. Onde cada mod funciona

    Atualizar, desligar e desinstalar
    Atualizar a lista de mods
    claude plugin marketplace update mare-mods
    Atualizar um mod
    claude plugin update nome-do-mod
    Desligar e religar
    claude plugin disable nome-do-mod · claude plugin enable nome-do-mod
    Desinstalar
    claude plugin uninstall nome-do-mod

    Confiança

    Você instala código na sua máquina. Leia antes.

    Um mod roda dentro do seu Claude Code. Por isso, tudo aqui é aberto e passa pelas mesmas regras antes de entrar.

    1. Código aberto

      Licença Apache 2.0. Cada linha de cada mod está no repositório, para ler antes de instalar.

    2. Testado a cada mudança

      Toda mudança passa por validação e testes automáticos de cada mod, no terminal e no app.

    3. Canário semanal

      Toda semana os mods são testados na versão mais nova do Claude Code. Se algo quebra, uma issue é aberta.

    4. Sem rede escondida

      Um mod só usa a rede se o README dele disser para onde vai e por quê.

    5. Sem segredos nem dados pessoais

      Uma varredura barra chaves, tokens, e-mails e caminhos pessoais em cada mudança.

    6. Um mod de cada vez

      Você instala só o que quer. Cada mod liga, desliga e sai sem mexer nos outros.

    Um aviso franco: a API de mods do Claude Code está em early access e pode mudar entre versões. Quando isso quebrar um mod, o canário avisa e a correção sai numa versão nova.
